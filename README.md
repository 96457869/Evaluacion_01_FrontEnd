# 📄 Currículum Vitae Web - Evaluación 01

¡Bienvenido a mi repositorio! Este proyecto contiene el desarrollo de mi Currículum Vitae en formato web, diseñado para la **Evaluación 01** de la asignatura de Programación FrontEnd.

## 🎯 Objetivo del Proyecto
Crear una página web estática utilizando **HTML5** y **CSS3** puros. El proyecto reproduce una estructura de layout predefinida (dos columnas y un encabezado), pero integra información profesional real y un diseño moderno orientado al área de la tecnología.

## ✨ Características Destacadas
* **Estructura Semántica:** Uso correcto de etiquetas HTML5 (`<header>`, `<main>`, `<aside>`, `<section>`).
* **Diseño Premium:** Implementación de variables CSS para la paleta de colores, sombras dinámicas (shaders) y bordes redondeados modernos (*squircles*).
* **Interactividad Visual:** Efectos `hover` en botones, tarjetas de experiencia y listas de habilidades que reaccionan al cursor.
* **Organización:** Código limpio y separado en directorios (`/css`, `/assets`).

## 🛠️ Tecnologías Utilizadas
* **HTML5**
* **CSS3**
* **Git & GitHub** (Control de versiones)
